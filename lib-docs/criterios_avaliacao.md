# Criterios de avaliacao

## Estrutura

- O projeto possui menu principal em `lib/main.dart`.
- A Fase 01 esta isolada em `lib/fases/fase_01/`.
- As fases futuras possuem pastas reservadas.
- A documentacao geral esta em `lib-docs/`.

## Fase 01

- Usa `sqflite`.
- Usa `openDatabase` diretamente.
- Cria as tabelas `estado` e `cidade`.
- Implementa CRUD completo de estado.
- Implementa CRUD completo de cidade.
- Usa SQL explicito.
- Usa `Map<String, dynamic>` para ler os registros.
- Nao usa DAO, Model ou Singleton.

## Documentacao

- Explica o objetivo da fase.
- Explica dependencias.
- Explica abertura do banco.
- Explica SQL basico.
- Inclui referencias para Flutter, pub.dev, sqflite e SQLite.
